# O Cavaleiro Supremo

## Introdução
O Cavaleiro Supremo é um jogo para navegador do gênero roguelike, onde o jogador controla um cavaleiro dourado que tem como missão sobreviver a uma horda de inimigos no maior tempo possível. O jogo foi desenvolvido por mim, Nickolas Markus da Silva Costa, utilizando a Godot Engine.

## Controles de Movimentação
* Cima = W
* Baixo = S
* Esquerda = A
* Direita = D

## Controles de Ataque
* Ataque = botão esquerdo do mouse
